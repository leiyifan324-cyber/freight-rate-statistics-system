Windows 10 / 11 · 64位 · v1.4.2

物流运价系统：照着做就能开始

不需要安装 Python，不需要编程。只采集文字；图片报价跳过。首次接入需要你亲自扫码登录QQ。

请先在独立测试群验收，再统计正式业务。程序不包含腾讯QQ。内置NapCat有独立的非商业使用限制；商用需要另行取得其作者授权。切勿上传账号Token和聊天数据到GitHub。

① 安装与登录（第一次做）

  1. 从本项目最新版下载 Setup 安装版，不是页面下方的“Source code”。双击安装，优先使用D盘推荐目录。没有D盘时会使用当前用户目录。
  2. 先从腾讯官网安装64位QQ。随后完全退出普通QQ，包括托盘图标。
  3. 安装结束勾选“安装NapCatQQ组件”和“启动物流运价统计系统”。NapCat组件保存在本系统安装目录的 NapCatQQ 文件夹。请用已加入目标群的QQ扫码登录；验证码、风控提示需要你本人处理。
  4. 打开NapCat启动日志显示的 WebUI 地址，使用日志中的WebUI Token登录。在“网络配置”启用 OneBot 11 WebSocket服务器：主机 127.0.0.1，端口 3001。设置访问Token后，在下一步的系统中填写相同Token。WebUI登录Token和OneBot访问Token不是同一个概念。

不要绑定 0.0.0.0 或把管理端口开放到公网。若NapCat菜单与此不同，请参照内置版本的官方说明，不要盲目复制其他版本配置。

② 配置自己的群和统计年度（第一次做）

  1. 双击桌面的“物流运价系统管理”，打开本机页面；也可用开始菜单“启动物流运价系统”。默认 群与线路管理。页面提示尚未配置群是正常的。
  2. 连接地址填 ws://127.0.0.1:3001，访问Token与NapCat OneBot一致。添加你自己的群号、群名及默认始发地；公开版不带任何实际群号。
  3. 检查线路与别名。如果贵港群不应采南宁始发，在该群“不统计的始发地”填“南宁”；南宁群相反填“贵港”。群名不会自动决定过滤规则。
  4. 点击“保存并自动应用”，等待状态为 connected。然后到 年度归档 填名称、开始日期，启用手动年度并确认。想从今天正式统计，就选今天；旧测试数据不会自动消失。
  5. 确认顶部不是“已停止采集”；如果已停止，点 开始采集。connected只代表连接成功，不代表采集开关已打开。

③ 每天使用

  1. 保持电脑、NapCat登录与网络正常；睡眠、关机、掉线期间没有送达程序的消息不能保证补回。
  2. 到“数据与报表”选群，查看报价明细、日均统计和Excel。用“不合格消息”查看拒绝原因；有歧义的文字不会猜价。
  3. 当天结束时点 停止采集 并确认，等待处理数变成0；核对当天数据，必要时按日期查询、预览并删除测试记录。
  4. 选择群和日期，点 生成当日图表。每个群分别生成；它不会自动停止采集。数据后来变化会提示图表过期，需要重生成。
  5. 下次开始工作时点 开始采集。暂停期间新消息不补采。年度结束用“年度归档”，不是每天点一次。

推荐文字：贵港到佛山大板120元/吨、到杭州红板200/220 35吨。报价数字不要拆开；车型、吨位、费用写明单位。每方报价不采集。

升级、常见问题

  • 旧版升级：先备份整个 data 和两份配置JSON；停止采集、等待队列和Excel完成，用开始菜单“退出后台程序（升级前使用）”，再安装到原目录。安装器保留已有配置和数据。便携版先备份，再用完整新包覆盖程序文件，不要单独替换EXE。
  • 页面打不开：用桌面入口重新启动；不要同时运行两份系统。若8765被其他软件占用，需要让维护人员修改本程序端口；不得强行结束不认识的进程。
  • 未连接：检查QQ是否在线、OneBot是否启用、地址/端口/Token是否一致。网络恢复后程序会尝试重连；QQ重新登录必须本人完成。
  • 有消息但无数据：检查采集开关、群白名单、线路范围、每群始发地排除规则、年度是否正在统计、消息是否属于未来日期或已重复。
  • Excel被占用：关闭Excel/WPS，等待重试；看到“待更新”不等于最新文件已成功覆盖。
  • 没有写入权限/磁盘不足：暂停采集，先恢复空间和目录权限，再检查日志及队列。未能写入磁盘的消息不能保证恢复；不要自行删除数据库。
  • 下载或安全提示：仅使用本项目GitHub Release。无商业签名，可能显示未知发布者；可以请维护人员比对同页SHA256SUMS.txt。若出现恶意软件拦截，不要关闭杀毒软件，先核验文件并反馈。

需要帮助时访问问题反馈，只提供脱敏的错误、Windows版本和复现文字，不上传QQ登录态、Token或客户聊天。

测试覆盖不等于任意电脑、任意QQ版本或任何自然语言都100%可用；以对应Release公开的验收报告为准。
