# 配置参考（唯一字段说明）

这是项目中配置字段的唯一完整说明。普通用户优先使用本机“群与线路管理”页面；只有高级选项才需要编辑JSON。修改前先备份，JSON必须使用UTF-8并保持语法有效。

## 管理页面字段

### NapCat连接

| 字段 | 说明 | 默认值 |
|---|---|---|
| OneBot WebSocket地址 | NapCat正向WebSocket服务器地址 | `ws://127.0.0.1:3001` |
| Access Token | 与NapCat网络配置完全一致；已保存值不会回传，输入框留空表示保留，勾选“清除”才会删除 | 空 |
| NapCat启动器路径 | 监督程序发现NapCat未运行时调用的EXE/BAT/CMD；可留空 | 空 |

### QQ群

| 字段 | 规则 |
|---|---|
| 群号 | 纯数字且不能重复；必须是采集QQ已经加入的群 |
| 群名称 | 仅用于页面显示；输出目录由群号稳定定位 |
| 默认始发地 | 消息未明确写始发地时使用，必须引用现有标准始发地 |

### 实时处理与Excel

| 字段 | 范围 | 默认值 | 说明 |
|---|---:|---:|---|
| 断线重连间隔 | 1～300秒 | 5秒 | OneBot连接断开后的重试等待 |
| 心跳检测间隔 | 5～300秒 | 15秒 | 长时间无事件时主动发送WebSocket心跳 |
| Excel批量追加等待 | 0～10秒 | 0.5秒 | 合并短时间内连续到达的消息，减少文件打开次数 |
| Excel汇总刷新间隔 | 10～3600秒 | 60秒 | 追加明细后，低频校准日/周/月/年汇总和图表 |

### 数据生命周期

生命周期配置位于“群与线路管理”页面，保存后随采集器热重载生效。上方“默认数据生命周期模板”适用于所有没有专属配置的群，以后新增群也自动继承；下方可以按群开启专属策略，关闭专属策略后立即恢复继承。各群按自己的有效维护间隔独立执行，不会删除 `pending` 或 `processing` 状态的消息。正式运价被清理后，Excel、历史日均价和图表会执行全量校准。

| 字段 | 范围 | 默认值 | 说明 |
|---|---:|---:|---|
| 启用自动维护 | 布尔值 | 开启 | 关闭后不执行自动清理 |
| 维护间隔 | 5～1440分钟 | 1440分钟（1天） | 启动后立即执行一次，随后按此间隔运行 |
| 正式运价保留天数 | 0～36500天 | 0 | `0` 表示永久保留；商业历史趋势默认不删除 |
| 消息去重记录保留天数 | 0～36500天 | 1 | 到期后仍受正式运价内容键查重保护 |
| 不合格记录保留天数 | 0～36500天 | 1 | 管理页“不合格”历史的保留时间 |
| 死信保留天数 | 0～36500天 | 1 | 只清理已进入 `dead_letter` 的事件 |
| 每日备份保留天数 | 1～3650天 | 7 | 只清理标准命名的每日ZIP备份 |

记录类保留天数中的 `0` 都表示永久保留。在线维护只执行短SQLite事务和 `PRAGMA optimize`，不会自动执行可能长时间锁库的 `VACUUM`。运行状态页显示每群使用“默认模板”还是“群专属”、生命周期状态、最近维护时间、本次及累计清理数量；维护失败只记录错误，不会中断WebSocket接收。

### 始发地和目的地

- 标准名称：统计汇总使用的统一名称，不能重复。
- 识别别名：市、区、县、镇及常见简称，用逗号或换行分隔。
- 同一个别名不能同时属于两个标准地区。
- 新增标准目的地后，自动与所有始发地构成可统计线路。
- 手动文本模式默认始发地：只用于手动粘贴文本统计，与每个QQ群自己的默认始发地相互独立。

### 货物与价格

- 标准小类：明细、内容去重和线路筛选使用的货物名称，至少保留一种。
- 识别别名：同一小类的常见写法；跨全部货物按最长别名优先匹配，同一别名不能属于两个小类。
- 归属大类：日、周、月、年汇总使用的分类；留空时继承“默认货物大类”。
- 消息未写货物时默认小类：默认仍为“大板”，可在页面选择其他现有小类。
- 货物线路筛选：可给某个小类或大类设置允许线路白名单。不设置即允许全部线路；小类规则优先于大类规则，只影响该货物，未开放线路记入“不合格”。
- 价格上限：超过此数值的报价视为非日均运价，不进入平均统计。

## qq_live_config.json

安装版位于 `%LOCALAPPDATA%\FreightQuoteSystem\qq_live_config.json`。

| JSON字段 | 类型 | 说明 |
|---|---|---|
| `ws_url` | 字符串 | OneBot WebSocket地址 |
| `access_token` | 字符串 | OneBot Token；属于敏感信息 |
| `napcat_launcher` | 字符串 | NapCat启动器绝对路径或相对安装目录的路径 |
| `group_ids` | 字符串数组 | 允许采集的群号 |
| `group_names` | 对象 | 群号到群名映射 |
| `group_default_origins` | 对象 | 群号到标准始发地映射 |
| `output_root` | 字符串 | 输出根目录；相对路径以配置文件目录为基准 |
| `rules_file` | 字符串 | 业务规则文件路径 |
| `accept_self_messages` | 布尔值 | 是否接收采集QQ自己发送的消息 |
| `ocr_enabled` | 布尔值 | 是否启用Windows图片OCR |
| `ocr_script` | 字符串 | OCR PowerShell脚本路径 |
| `status_dashboard.enabled` | 布尔值 | 是否启用状态与管理页面 |
| `status_dashboard.host` | 字符串 | 只允许 `localhost` 或IPv4回环地址，禁止公开监听 |
| `status_dashboard.port` | 整数 | 管理页端口，范围1～65535，默认8765 |
| `backup_retention_days` | 整数 | 旧版兼容字段；新配置由 `data_lifecycle.backup_retention_days` 同步写入 |
| `data_lifecycle.enabled` | 布尔值 | 是否启用自动生命周期维护 |
| `data_lifecycle.maintenance_interval_minutes` | 整数 | 自动维护间隔，5～1440分钟 |
| `data_lifecycle.processed_message_retention_days` | 整数 | 消息去重记录保留天数，0表示永久 |
| `data_lifecycle.rejected_message_retention_days` | 整数 | 不合格记录保留天数，0表示永久 |
| `data_lifecycle.dead_letter_retention_days` | 整数 | 死信保留天数，0表示永久 |
| `data_lifecycle.freight_record_retention_days` | 整数 | 正式运价保留天数，0表示永久 |
| `data_lifecycle.backup_retention_days` | 整数 | 每日ZIP备份保留天数，至少1天 |
| `group_data_lifecycle` | 对象 | 可选的群号到专属生命周期策略映射；没有键的群继承 `data_lifecycle` 默认模板 |
| `time_check_urls` | 字符串数组 | HTTPS可信时间候选网址 |
| `reconnect_seconds` | 数字 | OneBot断线重连间隔，最少1秒 |
| `heartbeat_seconds` | 数字 | WebSocket心跳检测间隔，默认15秒 |
| `excel_batch_seconds` | 数字 | 每群Excel批量追加等待，默认0.5秒 |
| `excel_full_refresh_seconds` | 数字 | 统计汇总全量校准间隔，默认60秒 |
| `rebuild_on_start` | 布尔值 | 启动时是否重建各群输出文件 |

仓库只提交 `config/qq_live_config.example.json`。真实配置、Token和群号不得提交Git。

## freight_rules.json

| JSON字段 | 类型 | 说明 |
|---|---|---|
| `default_origin` | 字符串 | 手动文本模式默认始发地 |
| `origin_groups` | 对象 | 标准始发地到别名数组 |
| `destination_groups` | 对象 | 标准目的城市到别名数组 |
| `board_types` | 字符串数组 | 旧版兼容字段；自动同步为 `cargo_types` 的标准小类名称 |
| `default_cargo_subcategory` | 字符串 | 消息未写货物时使用的现有标准小类 |
| `default_cargo_category` | 字符串 | 小类没有单独指定大类时继承的默认大类 |
| `cargo_types` | 对象数组 | 结构化货物规则；每项含 `name`、`aliases`、`category`，其中空 `category` 表示继承默认大类 |
| `cargo_route_scopes` | 对象数组 | 可选线路白名单；每项含 `level`（`subcategory`/`category`）、`cargo` 和 `routes`（标准始发地、目的城市） |
| `price_threshold` | 数字 | 进入平均运价的最高价格 |
| `invalid_line_keywords` | 字符串数组 | 命中即过滤的无效消息词 |
| `relative_date_aliases.today` | 字符串数组 | 今天类日期词 |
| `relative_date_aliases.tomorrow` | 字符串数组 | 明天类日期词 |
| `relative_date_aliases.day_after_tomorrow` | 字符串数组 | 后天类日期词 |
| `relative_date_aliases.today_and_tomorrow` | 字符串数组 | 今明两天类日期词 |
| `relative_date_aliases.tomorrow_and_day_after` | 字符串数组 | 明后两天类日期词 |

管理页面保存前会校验配置版本和全部字段，最多保留最近50份配置备份。两份配置通过事务日志和内部 generation 一起提交；进程在中途异常退出时，下次启动会自动完成或回滚未结束的提交。保存后系统会暂停接收、排空持久消息队列和Excel队列，再在同一进程内重新加载。直接编辑JSON时，应重启物流运价系统使其生效。
