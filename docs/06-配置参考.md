# 配置参考（唯一字段说明）

这是项目中配置字段的唯一完整说明。普通用户优先使用本机“群与线路管理”页面；只有高级选项才需要编辑JSON。修改前先备份，JSON必须使用UTF-8并保持语法有效。

## 管理页面字段

### NapCat连接

| 字段 | 说明 | 默认值 |
|---|---|---|
| OneBot WebSocket地址 | NapCat正向WebSocket服务器地址 | `ws://127.0.0.1:3001` |
| Access Token | 与NapCat网络配置完全一致；未设置则留空 | 空 |
| NapCat启动器路径 | 监督程序发现NapCat未运行时调用的EXE/BAT/CMD；可留空 | 空 |

### QQ群

| 字段 | 规则 |
|---|---|
| 群号 | 纯数字且不能重复；必须是采集QQ已经加入的群 |
| 群名称 | 用于页面和输出目录名称 |
| 默认始发地 | 消息未明确写始发地时使用，必须引用现有标准始发地 |

### 始发地和目的地

- 标准名称：统计汇总使用的统一名称，不能重复。
- 识别别名：市、区、县、镇及常见简称，用逗号或换行分隔。
- 同一个别名不能同时属于两个标准地区。
- 新增标准目的地后，自动与所有始发地构成可统计线路。

### 货物与价格

- 货物种类：可识别的货物名称，用逗号分隔，至少保留一种。
- 价格上限：超过此数值的报价视为非日均运价，不进入平均统计。

## qq_live_config.json

安装版位于 `%LOCALAPPDATA%\FreightQuoteSystem\qq_live_config.json`。

| JSON字段 | 类型 | 说明 |
|---|---|---|
| `ws_url` | 字符串 | OneBot WebSocket地址 |
| `access_token` | 字符串 | OneBot Token；属于敏感信息 |
| `napcat_launcher` | 字符串 | NapCat启动器绝对路径或相对安装目录的路径 |
| `group_ids` | 字符串数组 | 允许采集的群号 |
| `group_names` | 对象 | 群号到群名映射 |
| `group_default_origins` | 对象 | 群号到标准始发地映射 |
| `output_root` | 字符串 | 输出根目录；相对路径以配置文件目录为基准 |
| `rules_file` | 字符串 | 业务规则文件路径 |
| `accept_self_messages` | 布尔值 | 是否接收采集QQ自己发送的消息 |
| `ocr_enabled` | 布尔值 | 是否启用Windows图片OCR |
| `ocr_script` | 字符串 | OCR PowerShell脚本路径 |
| `status_dashboard.enabled` | 布尔值 | 是否启用状态与管理页面 |
| `status_dashboard.host` | 字符串 | 必须保持 `127.0.0.1`，不要公开监听 |
| `status_dashboard.port` | 整数 | 管理页端口，默认8765 |
| `backup_retention_days` | 整数 | 每群每日备份保留天数 |
| `time_check_urls` | 字符串数组 | HTTPS可信时间候选网址 |
| `reconnect_seconds` | 数字 | OneBot断线重连间隔，最少1秒 |
| `rebuild_on_start` | 布尔值 | 启动时是否重建各群输出文件 |

仓库只提交 `config/qq_live_config.example.json`。真实配置、Token和群号不得提交Git。

## freight_rules.json

| JSON字段 | 类型 | 说明 |
|---|---|---|
| `default_origin` | 字符串 | 手动文本模式默认始发地 |
| `origin_groups` | 对象 | 标准始发地到别名数组 |
| `destination_groups` | 对象 | 标准目的城市到别名数组 |
| `board_types` | 字符串数组 | 可识别货物种类 |
| `price_threshold` | 数字 | 进入平均运价的最高价格 |
| `invalid_line_keywords` | 字符串数组 | 命中即过滤的无效消息词 |
| `relative_date_aliases.today` | 字符串数组 | 今天类日期词 |
| `relative_date_aliases.tomorrow` | 字符串数组 | 明天类日期词 |
| `relative_date_aliases.day_after_tomorrow` | 字符串数组 | 后天类日期词 |
| `relative_date_aliases.today_and_tomorrow` | 字符串数组 | 今明两天类日期词 |
| `relative_date_aliases.tomorrow_and_day_after` | 字符串数组 | 明后两天类日期词 |

管理页面保存前会自动备份并校验两份配置；直接编辑JSON时，应重启物流运价系统使其生效。
