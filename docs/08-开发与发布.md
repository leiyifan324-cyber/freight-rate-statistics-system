# 开发、测试与发布

## 源码环境

```powershell
git clone https://github.com/leiyifan324-cyber/freight-rate-statistics-system.git
cd freight-rate-statistics-system
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-build.txt
```

复制示例配置后运行：

```powershell
Copy-Item config\qq_live_config.example.json qq_live_config.json
Copy-Item config\freight_rules.default.json freight_rules.json
python src\freight_app.py --mode supervisor
```

真实配置在 `.gitignore` 中，不应提交。

## 测试

```powershell
.\scripts\run_tests.ps1
```

测试覆盖群输出隔离、同内容查重、未来缓存、日期边界、SQLite增量、OCR、备份、Excel占用保护、配置管理接口和浏览器页面。

## 构建 Windows Release

需要安装 PyInstaller 与 Inno Setup 6：

```powershell
python -m pip install -r requirements-build.txt
.\scripts\build_release.ps1 -Version 1.0.0 -Python python
```

构建脚本先运行全部测试，再生成：

- `dist-release\FreightQuoteSystem-Setup-v1.0.0.exe`
- `dist-release\FreightQuoteSystem-Portable-v1.0.0.zip`
- `dist-release\SHA256SUMS.txt`

## Git工作流

- 功能分支：`feature/...`
- 修复分支：`bugfix/...`
- 提交信息遵循Conventional Commits。
- 正式版本使用语义化标签，例如 `v1.0.0`。
- Release只上传构建脚本生成的三个资产。

发布前检查：测试通过、示例配置无真实群号和Token、Git历史无数据库/日志、安装和卸载在隔离目录验证、Release校验值正确。封装后的首次启动可用 `tests/verify_packaged_release.ps1` 在未占用端口上进行冒烟测试。
