# 手动统计年度与归档

在系统顶部点击“年度归档”，或打开 `http://127.0.0.1:8765/?view=archive`。

本功能让你决定一个统计年度何时结束，而不是必须到元旦或春节才结束。可以称为“2026经营年度”“2026下半年—2027上半年”等，名称由你填写。页面统一控制全部已配置QQ群，但各群数据和报表仍独立。

## 1. 第一次设置

升级后不会替你开年或关账。未启用时，原来的春节自动统计保持不变。

1. 填写“统计年度名称”和“开始日期”。第一次允许选择过去的日期，例如本年1月1日。
2. 点击“启用手动年度”，阅读说明后确认。
3. 系统把已入库、在开始日之后且符合线路/货物配置的记录纳入本年度。未来生效报价到日期后才进入日均。

**已有测试数据不会因为开启手动年度而自动去除。** 如果测试数据不应参与，先在“数据与报表”按日期查询，预览确认后删除，或选择不包含测试期的开始日。本功能本身不删除报价。

启用手动模式后，系统不再按春节自动替这些群切换年度。旧报表保留为历史文件，不再当作当前手动年度更新。手动粘贴文本统计模式不受影响。

## 2. 结束本年度

1. 确认当前年度名称和起始日。
2. 选择“统计截止日期”，必须在本年度开始日和今天之间。
3. 点击“预览并结束本年度”：查看各群的拟归档报价条数。
4. 确认后，本年度立即停止累计。系统保存关账时的固定快照，并后台生成Excel和CSV。
5. 等待状态变为“已归档 · 等待开启”，点击“查看汇总”或“下载年度Excel”。

归档包含**确认关账时已入库**且生效日期在开始日与截止日之间的有效报价（两端均包含）。若今天下午关账，即使截止日选今天，今晚才收到的消息也不会再进这个快照。

预览和确认之间仍可能收到新消息，因此最终数量可能略有增加。服务端会重新核验状态并在事务内取数。如果有已收到的群消息正在排队处理，会提示稍后重试，不会一边切换年度一边把旧队列补进新年度。

关账暂不提供直接撤销。不要通过修改数据库来反复开关，请先检查年度名称、截止日期及测试数据。归档失败不是数据丢失：快照仍在，关闭占用的Excel、检查磁盘空间后点击“重试归档”。重试只使用原快照，不重新取数。

## 3. 暂停期间

按本次需求，暂停期间数据**不计入任何年度，也不自动补进下一年度**。

- NapCat和原始消息采集继续工作；这些记录仍可在“数据与报表”查询。
- 当前年度日均为空；手动当前Excel会显示无当前统计年度。
- 以前关账的数据仍在“年度归档记录”里。
- 原有数据保留/清理配置仍适用；“保留原始记录”不意味着绕过已有清理规则永久保留。

归档失败或正在生成归档时，也已停止本年度累计；需先完成归档才能开下一年度。

## 4. 开启下一年度

准备开始时填写新的年度名称，点击“开启下一年度”并确认。

- 后续年度从**操作当天**开始，不倒填暂停期，也不能提前指定未来日期。
- 新年度不纳入开启前已经入库的记录，包括暂停时收到但生效日落在新年度的报价。
- 开启后新收到的报价，只有生效日期在新年度范围内才进入统计。
- 年度按“天”划分，两个年度不允许重叠。若上年度截止日是今天，新年度最早明天开启；若上年度截止在昨天或更早，可以今天开启。

例如：9月8日结束旧年度，截止9月8日；9月9日—9月15日暂停；9月16日点击开启新年度。那么旧年度保留关账时的汇总，暂停期不计，新年度从9月16日开启后的记录开始。

## 5. 怎样看结果

| 页面/文件 | 代表什么 | 后续会不会变化 |
|---|---|---|
| 数据与报表 → 原始报价 | 所有仍保留的原始记录；可见本年度/历史暂停期提示 | 新消息、删除等会改变 |
| 数据与报表 → 日均统计 | 当前手动统计年度内、符合查询条件的日均 | 会更新；暂停时为空 |
| 手动年度统计/当前/年度统计汇总.xlsx | 当前年度的明细及大小类日/周/月/年汇总 | 新数据或删除后重建；Excel被占用时稍后重试 |
| 年度归档 → 查看汇总 | 该次关账的固定年度汇总 | 不自动改写 |
| 手动年度归档/序号/年度统计汇总.xlsx | 该次关账的固定明细、汇总Excel | 不自动改写 |
| 原来的春节报表/图表 | 启用手动年度前保留的旧模式输出 | 启用后不作为当前手动年度更新 |

“查看汇总”按群展示线路、货物大类、年度均价、数据月份数、参与均价的报价数。Excel另有小类汇总及详细数据。明细条数可能大于参与均价条数，因为超过阈值的整车价保留在明细中，不参与均价。

统计口径沿用原系统：当天同线路同货物的报价先求日均；每月对有数据日的日均求平均；年度对有数据月份的月均求平均。**不是把全年所有原始报价直接平均。** 没有报价的月份不按0元计算。周为从年度开始日算起的连续7天。

## 6. 保存与备份

在QQ输出根目录（默认 `data`）新增 `统计年度管理.db`，保存年度状态、暂停期排除记录和固定归档快照。每群目录下新增 `手动年度统计/当前` 与 `手动年度归档/序号`。

不要只复制某个群的报价数据库来迁移整个年度功能。完整备份/迁移时应先退出系统，复制**整个输出根目录**，同时保留配置文件。原来的每群日常备份不等于中央年度管理数据库的完整备份。

归档快照和源记录相互独立：如果关账后才发现测试数据混入，删除源记录不会自动修订已归档年度。应在关账前先核对数据；需要修订历史快照时另行安排恢复或更正，不要直接编辑数据库。
