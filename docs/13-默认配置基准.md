# 公开版默认配置与升级保护

v1.4.2发布通用版，没有实际群号、群名和QQ登录信息。你本机已保存的个人配置不受公开模板变化影响；这不是第三方安全认证或识别率保证。

| 设置 | 新安装默认值 |
|---|---|
| QQ群、群名称、群默认始发地 | 空，首次在页面添加 |
| 标准始发地 | 贵港、南宁；武鸣归为南宁别名 |
| 目的城市 | 佛山、杭州、成都、重庆、长沙、南昌、武汉、西安、福州、临沂 |
| 手动文本默认始发地 | 贵港 |
| 货物 | 大板、红板、拼板；未写时默认大板，归属板材 |
| 整车价阈值 | 1000，超过阈值保留明细但不计均价 |
| 群始发地排除 | 空；新增群后手动设置，见按群始发地过滤说明 |
| 采集输入 | 仅文字，OCR关闭 |
| OneBot连接 | ws://127.0.0.1:3001；访问Token空，建议自行设置 |
| NapCat启动器 | 安装目录内NapCatQQ/Start-NapCat.cmd |
| 正式运价保留天数 | 0，不按天自动删除 |
| 已处理标记、拒绝、死信 | 默认1天；待处理队列不自动清理 |
| 日常备份 | 默认7天 |

源码模板为config/qq_live_config.example.json和config/freight_rules.default.json。构建后的根目录是qq_live_config.json和freight_rules.json；不包含年度管理数据库、采集控制数据库或原报价。

新用户添加自己的群并检查默认始发地、排除项和线路，再到年度归档启用所需统计年度。连接在线不等于采集已开始，需检查顶部采集开关。

已有用户升级必须安装到原目录；安装器保留两份配置及业务数据，不会把原群号改为空。公开默认文件不能用来恢复你的个人设置；恢复请使用个人配置备份，两份JSON配套恢复，并保留整个data。

安装默认路径优先D盘，无D盘时用当前用户目录；升级沿用既有安装目录。旧版个人NapCat路径也保留，不自动迁移。
