# 真实消息格式识别（1.2.1）

系统使用可编辑业务规则及文本解析器，并非在线学习的大模型。新增群消息不会自行修改线路白名单或训练模型权重。格式优化需要样本核对和回归测试。

## 支持与保护

| 格式示例（线路须在配置范围内） | 处理 |
|---|---|
| 大板115-120、200/220、165／170 | 保留价格集合及其最低/最高/平均值，不作为日期 |
| 大板110 35-36吨 | 运价110，吨位不参与价格统计 |
| 大板13-13.75 165/175 | 车长不作为日期或运价 |
| 大板2装1卸距离3公里 3400-3500 | 装卸次数、距离不参与价格统计 |
| 武鸣红板到佛山120 | 货物为红板，不回退到默认大板 |
| 大板245加1 | 进入未识别，需明确最终报价 |
| 大板150 160 | 多个未说明关系的价格，进入未识别 |
| 22号武鸣到佛山120 | 缺少月份，进入未识别；请补充完整日期 |

短日期如“9/10”请写在行首，或写成“9/10装货”；完整日期推荐“2026-09-10”。“今明”“明天”“后天”保留原配置行为。

## 使用边界

- 范围外的地区仍会拒绝。格式正确不代表属于当前统计范围，不用默认始发地代替明确写出的未知始发地。
- 每行应是一条完整线路和报价。跨行断句、独立的“有车了”、跨消息撤销和多装货地的指代，目前不能可靠关联，不应当成已支持格式。
- 图片必须先获得有效OCR文字；这次文字格式回归没有验证图片识别准确率。
- 未配置的货物名称仍可能回退到默认货物。新增品类需维护配置，不能将自动归类当成人工确认。
- 现有报表没有按“元/吨、元/方”建立独立计价单位维度。数字识别成功不表示这些不同单位可直接混算。
- 大于现有阈值的报价仍按整车价处理。不得据此推断所有小额报价的单位。
- 本次不改历史已入库数据，也不补采或重新入库历史未识别信息。修正后的逻辑用于后续消息；如要修正历史，先备份并制定筛选范围。

## 本地回归

运行 `tests/test_quote_format_learning.py`。测试在独立临时目录生成模拟事件，覆盖价格/日期/货物格式、消息去重和文本导入路径，不连接生产NapCat或生产数据库。
