# 阶段一：完整安装

## 1. 准备条件

- 64 位 Windows 10 或 Windows 11。
- 可以正常联网。
- 一个已经加入目标报价群的QQ账号，建议使用专用账号。
- Microsoft Excel不是运行必需，但查看生成的 `.xlsx` 文件时建议安装。

## 2. 安装物流运价系统

1. 打开项目的 [GitHub Releases](https://github.com/leiyifan324-cyber/freight-rate-statistics-system/releases)。
2. 下载最新 `FreightQuoteSystem-Setup-vX.Y.Z.exe`。
3. 双击安装，优先推荐 `D:\FreightQuoteSystem`；没有D盘时默认当前用户的 `%LOCALAPPDATA%\FreightQuoteSystem`。已有安装会沿用原路径，不要求管理员权限。安装目录必须可写。
4. 安装结束时保留“安装NapCatQQ组件（不包含QQ）”和“启动物流运价统计系统”选项。

Windows可能提示“未知发布者”，原因是开源发行包没有商业代码签名证书。请只从本项目GitHub Release下载，并可用下列命令核对校验值：

```powershell
Get-FileHash .\FreightQuoteSystem-Setup-v1.4.2.exe -Algorithm SHA256
```

结果应与同一Release中的 `SHA256SUMS.txt` 一致。

### 便携版

不希望安装时，下载 Portable ZIP，解压到一个固定且可写的目录，然后双击 `启动系统.bat`。不要直接在压缩包内运行，也不要在运行后随意移动目录。

## 3. 安装QQ与NapCatQQ

1. 自行安装腾讯提供的[官方64位QQ](https://im.qq.com/pcqq/index.shtml)。本项目和Release不包含QQ。
2. 安装物流系统结束时运行“安装NapCatQQ组件（不包含QQ）”；也可从开始菜单再次打开“安装或更新NapCatQQ”。
3. 安装脚本会校验内置官方 `NapCat.Shell.Windows.Node.zip` 的SHA-256，再原样解压到 `安装目录\NapCatQQ\v4.18.19`，并生成稳定启动器 `安装目录\NapCatQQ\Start-NapCat.cmd`。旧版已保存的外部NapCat路径不会被覆盖。
4. 首次运行启动器，使用手机QQ扫码登录。

NapCatQQ采用独立的[限制再分发许可](https://github.com/NapNeko/NapCatQQ/blob/main/LICENSE)，其中包含非商业使用限制。发行包保留完整许可、官方来源、版本和校验值；商业部署前必须取得NapCat作者额外授权。

## 4. 安装结果

开始菜单中应出现：

- 启动物流运价系统
- 群与线路管理
- 手动文本统计
- 安装或更新NapCatQQ
- 使用说明

安装时默认勾选“登录 Windows 后自动启动统计系统”，安装器会尝试为当前用户创建 `FreightRateStatisticsSystemAutoStart` 登录任务；受限电脑可能不允许创建，不影响手动双击启动。完成后打开安装目录的“快速开始.html”，或继续阅读 [首次部署](02-首次部署.md)。QQ登录、OneBot启用和群配置仍需本人首次完成，不能省略。
