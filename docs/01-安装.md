# 阶段一：完整安装

## 1. 准备条件

- 64 位 Windows 10 或 Windows 11。
- 可以正常联网。
- 一个已经加入目标报价群的QQ账号，建议使用专用账号。
- Microsoft Excel不是运行必需，但查看生成的 `.xlsx` 文件时建议安装。

## 2. 安装物流运价系统

1. 打开项目的 [GitHub Releases](https://github.com/leiyifan324-cyber/freight-rate-statistics-system/releases)。
2. 下载最新 `FreightQuoteSystem-Setup-vX.Y.Z.exe`。
3. 双击安装，保持默认位置即可。默认安装到当前用户的 `%LOCALAPPDATA%\FreightQuoteSystem`，不要求管理员权限。
4. 安装结束时勾选“启动物流运价统计系统”和“打开首次配置页面”。

Windows可能提示“未知发布者”，原因是开源发行包没有商业代码签名证书。请只从本项目GitHub Release下载，并可用下列命令核对校验值：

```powershell
Get-FileHash .\FreightQuoteSystem-Setup-v1.0.0.exe -Algorithm SHA256
```

结果应与同一Release中的 `SHA256SUMS.txt` 一致。

### 便携版

不希望安装时，下载 Portable ZIP，解压到一个固定且可写的目录，然后双击 `启动系统.bat`。不要直接在压缩包内运行，也不要在运行后随意移动目录。

## 3. 安装 NapCatQQ

NapCatQQ是QQ消息接入组件，不包含在本系统发行包中。

1. 打开 [NapCatQQ 官方 Releases](https://github.com/NapNeko/NapCatQQ/releases/latest)。
2. 下载官方 Windows 一键包 `NapCat.Shell.Windows.OneKey.zip`。
3. 解压后按其[官方文档](https://napneko.github.io/)运行安装程序。
4. 记录最终的启动器路径，例如 `C:/NapCatQQ/launcher-user.bat`。

NapCatQQ采用独立许可并限制商业用途；请阅读其[许可文本](https://github.com/NapNeko/NapCatQQ/blob/main/LICENSE)。本项目不修改或重复分发NapCatQQ。

## 4. 安装结果

开始菜单中应出现：

- 启动物流运价系统
- 群与线路管理
- 手动文本统计
- 使用说明

安装时默认勾选“登录 Windows 后自动启动统计系统”，安装器会为当前 Windows 用户创建 `FreightRateStatisticsSystemAutoStart` 登录任务；如不需要可取消勾选。完成后继续阅读 [首次部署](02-首次部署.md)。
