# 每日出图与采集控制

## 推荐每日操作

1. 开始工作时确认NapCat在线，在页面顶部点击“开始采集”。显示“开关已开启”仅表示允许采集，实际接收仍需连接在线。
2. 当天结束时点击“停止采集”，确认后等待“已停止采集”。已接收消息会完成处理；停止期间新消息不入库，不生成拒绝记录。NapCat本身不退出。
3. 到“数据与报表”检查当天报价，必要时删除测试/错误数据。
4. 选择QQ群、统计日期、始发地与目的城市，点击“生成当日图表”。可以选择过去日期，不能选择未来日期。
5. 等待完成，下载PNG及同一快照生成的“当日报价与统计.xlsx”。后续补录、删除或规则变更使日报过期时，页面会提示“需要重新生成”。

采集控制全群生效，不影响已存数据。停止状态保存在数据根目录“采集控制.db”，重启后不会自动开始。恢复后不补采停止期间接收到的消息，并按OneBot秒级消息时间排除暂停区间的迟到历史事件；重启前已经接收并入队的消息仍可恢复完成。

## 出图口径与保存位置

- 与当前年度统计保持一致：按报价生效日期取数，排除当前年度外/暂停年度期记录、不允许线路及超过价格阈值的整车报价。
- 每条柱形为“始发地→目的城市 / 货物大类”的日均价，标明参与报价数。一天数据不画虚构的时间走势；多于12行分图输出。
- 生成时读取一份固定数据快照，Excel与PNG使用相同记录。图上写明日期、群名、生成时间和口径，不代表此后永不变化。
- 文件位于 `data/QQ群_<群号>/每日图表/<日期>/<版本标识>/`。重新生成创建新版本，旧图不覆盖；可以在报表文件列表查看以前的输出。
- 当前手动年度的Excel/CSV仍自动更新。旧`charts`/`小类统计`中的PNG属于旧模式输出，不能当作当前年度最新结果。
- “生成当日图表”不停止采集，也不结束年度；“停止采集”不等于“年度归档”。年度归档继续使用原来的页面。

## 失败与边界

- 没有参与统计的报价时明确提示，不生成空图或0均价。
- 有已接收消息排队时，应等队列完成再出图。
- 正在生成时禁止重复提交；磁盘写入/绘图失败不发布半成品，页面提示重试；程序中断后显示上次任务中断。
- 本版本没有顺带修复已知的多行图片OCR合并问题；采集图片仍须留意这一已知限制。
