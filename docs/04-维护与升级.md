# 阶段四：维护、升级、备份与卸载

## 日常维护

- 状态页：`http://127.0.0.1:8765/`
- 系统日志：`安装目录\data\logs\物流运价系统.log`
- 每群备份：`安装目录\data\群名称_群号\备份`
- 配置备份：`安装目录\配置备份`

日志达到5MB后轮转，保留最近10份。每群每日生成ZIP备份，默认保留30天。

## 升级本系统

1. 关闭打开的Excel文件。
2. 从GitHub Release下载更高版本安装器并核对SHA-256。
3. 直接覆盖安装到原目录。
4. 安装器保留 `qq_live_config.json`、`freight_rules.json`、数据库和输出数据。
5. 打开状态页确认连接，并用一条测试报价验收。

升级前仍建议手动复制整个 `data` 和两份JSON配置到外部磁盘。

## 升级 NapCatQQ

只从NapCatQQ官方Release升级。升级可能改变启动器目录或OneBot配置：

1. 先备份NapCat配置。
2. 完成官方升级和扫码登录。
3. 确认 WebSocket服务器仍为 `127.0.0.1:3001`，Token未变化。
4. 若启动器路径变化，在本系统管理页更新。
5. 验证系统状态为 `connected`。

## 从备份恢复

1. 退出Excel并停止物流运价系统。
2. 找到对应群“备份”目录中的日期ZIP。
3. 将当前群输出目录先复制到安全位置，不要直接删除。
4. 解压备份，恢复 `运价数据.db`、`qq_chat.txt` 和需要的汇总文件。
5. 重新启动系统，检查SQLite和Excel数据。

配置误改时，从 `配置备份\时间戳` 恢复 `qq_live_config.json` 和 `freight_rules.json`。

## 卸载

在 Windows“设置 → 应用”中卸载“物流运价统计系统”。卸载器会删除登录任务并停止程序。

用户生成的数据库、Excel、配置和备份可能会被保留。确认不再需要后再手动删除 `%LOCALAPPDATA%\FreightQuoteSystem`；删除前应先复制重要数据。NapCatQQ需按其官方方式单独卸载。
