# 数据查询与报表管理（1.2.0）

打开系统管理网页，点击顶部“数据与报表”。默认端口下可直接访问 `http://127.0.0.1:8765/?view=data`。

## 查询报价

1. 在右上方选择QQ群；所有查询、删除和文件操作均限于当前选中的群。
2. 在“报价明细”选择全部报价、正式识别、待生效报价或不合格消息。
3. 可填写日期范围、始发地、目的城市、货物小类、平均报价上下限和关键词，点击“查询数据”。关键词匹配原文、发布人和拒绝原因。
4. 默认每页25条，可以改为50或100条。使用上一页、下一页浏览历史，不受原运行状态页80条限制。
5. 点开“查看详情”查看原始消息、拒绝原因和记录时间。

报价日期筛选依据生效日期；不合格消息依据消息日期，且不使用线路、货物和价格筛选。正式识别包含历史年度，待生效指生效日在当前可信日期之后。因当前货物线路规则不再允许的旧报价仍能查询和删除，但会标注“不参与统计”。

## 查看统计和输出文件

- “日均统计”根据当前查询条件重新计算，可切换货物大类/小类；使用既有日均计算规则，未来报价、不允许的线路和超过配置价格阈值的报价不参与。
- “Excel / CSV / 图表”列出当前群生成的报表，包含周、月、春节年度、大小类以及历史归档。
- 点击Excel可直接在网页查看内容，切换工作表；CSV支持分页预览；PNG图表直接显示。
- 点击“下载原文件”保留完整Excel/CSV；文件仍在原 `data/QQ群_群号` 目录中持续生成。
- 日均统计来自数据库，文件预览来自最近生成的输出；报表正在更新时页面会显示提示。关闭占用的Excel后，待更新副本会在后续刷新中替换原文件。

## 删除错误数据

1. 先查询定位目标记录，可点行末“删除”，或勾选本页记录后点“删除已选”。每次最多100条。
2. 确认弹窗中的群名、记录类别和数量，再点“确认删除”；取消不会修改数据。
3. 数据库记录删除后，网页查询与日均统计立即反映新数据，Excel、CSV和图表由后台重建。点击“刷新报表列表”检查更新状态。

删除确认有效期5分钟；确认期间记录如被自动维护等其他流程改变，系统要求刷新后重新选择。删除不影响其他群，也不删除群配置。不得以清理去重记录代替删除报价。

每群数据库的 `deleted_data` 表保存删除前内容、批次和时间；这是本机可追溯记录，目前未提供网页撤销按钮。被手动删除的同内容报价会被拦截，避免旧消息重放后重新参与统计。正式数据库清空后也不会从旧TXT重新导入。待同步标记保存在数据库中，异常退出后会继续同步。

## 接口与开发

只对本机管理页面提供接口：

- `GET /api/data/options`：群、地区和货物选项。
- `GET /api/data/records`：`group_id` 必填；`kind/start/end/origin/destination/cargo/min_price/max_price/q/page/page_size` 可选。
- `GET /api/data/statistics`：同查询条件，`level` 为 `category` 或 `subcategory`。
- `GET /api/data/files`、`file-preview`、`file`：报表列表、工作表/CSV预览及文件内容。
- `POST /api/data/delete-preview`：`group_id/type/ids`，返回短期确认令牌。
- `POST /api/data/delete`：`token/confirm`，复核并删除令牌对应的精确记录。

写操作延用Host、Origin与CSRF校验。文件接口不接受越界路径，且不提供数据库、配置和备份文件。新增源码模块为 `src/freight_data.py` 与 `src/freight_data_ui.py`。
