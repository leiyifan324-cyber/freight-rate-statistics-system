# 按群始发地过滤（1.3.2）

在“群与线路管理 → QQ群 → 不统计的始发地”填写标准名称；多个用逗号分隔，留空表示不额外过滤。点击“保存并自动应用”生效。

公开版没有预置群。配置示例：为贵港群排除南宁，为南宁群排除贵港；测试群可不额外限制。新增群不会只因群名含某个地名就自动过滤，需要自行填写。下文10001、10002均为合成示例标识，实际使用请替换。

识别顺序：读取消息 → 提取线路 → 归并始发地别名或使用本群默认始发地 → 检查本群排除列表 → 入库/统计。当前武鸣归为南宁，港北/港南/覃塘归为贵港，故相应别名也受过滤。未写始发地不能凭空确认真实起点，仍按群默认值，建议原消息明确标注始发地。

不是对整条消息搜索地名，也不把被排除始发地强行改为本群默认值。命中行记入“不合格”并显示“本群不统计始发地为…”，不写正式报价或待生效报价；同条消息的其他合格行继续统计。按方/负价过滤继续生效。独立手动文本模式没有QQ群上下文，不套用QQ群过滤。

仅影响设置生效后处理的新消息，包括后续处理的队列消息；不自动删除、重命名或隐藏历史报价。历史数据如果需要清理，另行在数据页面确认范围后操作。

配置文件字段：

```json
"group_excluded_origins": {
  "10001": ["南宁"],
  "10002": ["贵港"]
}
```

列表使用“始发地范围”里的标准名称，不直接填别名。不能排除本群自己的默认始发地；若修改默认值或删除标准地名，需要同步修改过滤列表。旧配置没有此字段时不额外限制；旧客户端保存时省略字段保留已有规则，明确提交空列表才清空。
