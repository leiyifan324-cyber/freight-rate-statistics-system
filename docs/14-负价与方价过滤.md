# 1.3.1：负价与方价过滤

2026-09-08，按用户确认的采集范围更新：

| 输入示例 | 处理 |
|---|---|
| 南宁到佛山大板 运费=-987元/吨 | 拒绝负价，不把987当正价 |
| 南宁到佛山大板37-38元/方 | 不采集按方计价 |
| 南宁到佛山大板每立方米40元 | 不采集按方计价 |
| 南宁到佛山大板40元/m³ | 不采集按方计价 |
| 南宁到佛山大板120元/吨 | 正常采集 |
| 南宁到佛山大板120-125 | 正常区间价，均价122.5 |
| 南宁到佛山大板120元/吨，货量30方 | 正常采集；30方是货量而非单价单位 |

同条群消息按行过滤，不会因其中一行不合格而丢掉其他有效行。不合格消息中可查到“按方/立方米计价的运价不采集”或“报价含负数或疑似负价”等原因，但不会作为正式运价参与报表。

这次改变只约束新的识别入口；已经入库的旧数据、已归档快照、现有默认群及线路配置不删除、不迁移。未标明单位的正常运价仍按原规则处理，不推测它是方价。
