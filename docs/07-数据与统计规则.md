# 数据与统计规则

## 信息提取

每条有效报价至少需要：目的地、货物种类和价格。始发地可明确写出，也可使用QQ群默认值。地区别名归入标准城市，但“具体目的地”仍保留区县信息，例如“佛山南海”和“佛山顺德”是不同明细线路。

价格列表支持单价和多价格写法，最终输出统一保留三位小数。

## 日期与未来缓存

- 今天、今日、今晚：当天正式数据。
- 明天、明日、明早、明晚：下一天缓存。
- 后天：第二天缓存。
- 今明两天：拆为今天和明天两条生效记录。
- 明后天：拆为明天和后天两条缓存。
- 支持 `8月15日`、`2026年8月15日`、`8/15`、本周/下周星期表达。

缓存只接受严格晚于可信今天的日期。日期到达后自动转为正式数据并从缓存输出中消失；过去日期不会进入未来缓存。

## 查重

正式数据和未来缓存共同使用内容查重。查重键为：

`生效日期 + 标准始发地 + 具体目的地 + 货物种类 + 完整价格集合`

发布人和消息ID不参与内容查重，因此同一天不同人转发同一报价只统计一次。日期、地点、货物或任一价格不同则保留为不同数据。

## 日统计

每天按线路和货物汇总平均、最低、最高价格及报价数。日均数据保留在CSV和Excel中，不生成日价格走势图。

## 周统计

从观察起点开始，每7个自然日为一个观察周。完整7天后形成周数据；周平均是周期内实际有数据日期的日均价算术平均，同时记录观察天数、数据天数和覆盖率。

## 月统计

按自然月处理28、29、30、31天和闰年2月。部署首月从实际部署日开始；即使不足整月，也作为该月观察数据。月平均以实际有数据日期的日均价计算，并标记进行中或完整。

## 年统计

连续12个观察月构成一个观察年。年度走势图以月为基本单位，年平均对已有月平均价等权计算；满12个月后标记完整，未满时保留临时年数据和月份覆盖率。

## 输出和数据源

- SQLite `运价数据.db`：正式增量数据源。
- `报价明细.csv`、`待生效运价.csv`、`历史每日平均运价.csv`。
- `每周平均运价.csv`、`每月平均运价.csv`、`每年平均运价.csv`。
- `物流报价汇总.xlsx`：报价、缓存和全部周期工作表。
- `charts`：周、月、年走势图。
- `未识别消息.csv`：提取失败原因及原始消息审计。

没有报价的日期不会人为补造价格；覆盖率字段用于判断样本完整度。
