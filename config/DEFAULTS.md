# 公开通用版默认配置（v1.4.2）

用户已确认：公开GitHub版本清空实际群号和群名，保留线路与识别规则。

- qq_live_config.example.json：没有预置群、群名、群默认始发地或群排除项；Token为空，OCR关闭，仅采集文字。新用户通过页面添加自己的群。
- freight_rules.default.json：保留贵港/南宁2个标准始发地、10个目的城市、别名、货物与价格规则，可在页面修改。
- 新安装的NapCat启动器使用相对路径 NapCatQQ\Start-NapCat.cmd，组件跟随安装目录。升级不会覆盖原配置中的旧路径。
- 所有运行数据库、年度、采集开关、聊天、QQ登录态、个人配置版本令牌均不进入模板。

build_release.ps1将模板复制进安装包；安装器仅在目标配置不存在时安装默认值，不把旧配置覆盖为空。不要用公开模板覆盖个人已配置的生产文件。

测试通过tests/fixtures/synthetic_groups.json单独构造三个合成群，不使用实际QQ群标识。仓库历史中的v1.1.x文档是历史版本说明，新安装优先参考快速开始.html与v1.4.2 Release说明。
