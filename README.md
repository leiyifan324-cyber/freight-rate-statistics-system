# 物流运价统计系统

面向 Windows 的 QQ 群物流报价采集与统计工具。系统通过 NapCatQQ 接收指定群消息，识别始发地、目的地、货物、价格和生效日期，按群独立生成 Excel、CSV 与周/月/年走势图；同时保留手动粘贴文本的统计方式。

## 普通用户下载

进入 [最新版下载](https://github.com/leiyifan324-cyber/freight-rate-statistics-system/releases/latest)，下载 Assets 中的安装包（不要下载“Source code”）：

- `FreightQuoteSystem-Setup-vX.Y.Z.exe`：推荐，自动安装并配置开机登录后运行。
- `FreightQuoteSystem-Portable-vX.Y.Z.zip`：免安装便携版。
- `SHA256SUMS.txt`：下载文件校验值。

本软件面向 64 位 Windows 10/11；实测环境以Release报告为准。安装包包含Python运行时、统计依赖和校验过的NapCatQQ Windows Node官方组件，不需要安装Python或编程；不包含腾讯QQ。你需要自行安装[官方64位QQ](https://im.qq.com/pcqq/index.shtml)，扫码登录并按说明启用OneBot连接。

新手先看安装包内可双击打开的 **快速开始.html**：安装→扫码与连接→添加自己的群→启用统计年度→开始采集。新安装优先D盘，NapCat组件跟随安装目录；没有D盘时使用当前用户目录。已有安装升级保留原路径、配置与数据。公开版不带任何实际群号。

## 主要能力

- 每日可手动停止/开始全部群采集，停止状态重启后保留；按日期与线路生成固定快照图表及配套Excel，数据变化会提示重新生成，见[每日出图与采集控制](docs/16-每日出图与采集控制.md)。

- 公开默认模板保留线路与识别规则，群号、群名和访问Token为空，见[默认配置基准](docs/13-默认配置基准.md)。

- [手动统计年度与归档](docs/12-手动年度归档.md)：自主决定何时结束本年度、暂停、开启下一年度；保留固定汇总与Excel。

- 多QQ群白名单采集，每个群数据库、Excel、图表和备份完全独立。
- 群输出使用稳定的 `data\QQ群_群号` 目录；修改群名称不会切换或丢失原历史目录。
- WebSocket接收与统计处理解耦；消息先写入每群SQLite持久收件箱，再由独立串行工作线程处理，异常退出后可重放。
- 消息未写始发地时使用群默认始发地；支持城市、区县、乡镇别名归一化。
- 同日相同货物、始发地、具体目的地和全部价格只统计一次，不受发布人影响。
- 货物支持“小类识别与去重、大类独立汇总”，并可按小类或大类设置特定线路白名单；未配置货物不受其他货物规则影响。
- 明天、后天、明后天、明确日期和星期报价先进入未来缓存，到期自动转为正式数据。
- 未来缓存同样查重，且拒绝今天或过去日期进入缓存。
- 当前默认仅采集文字，图片跳过，不进行OCR；复杂数字有歧义时不猜价入库，未识别文字保留原因，见[纯文本采集说明](docs/17-纯文本采集与格式边界.md)。图片形式的统计图表输出仍保留。
- 日均数据保留在 Excel，图表输出周、月、年趋势，价格统一保留三位小数。
- 联网可信时间、SQLite增量存储、日志轮转、每日备份、Excel占用保护。
- “群与线路管理”页提供默认生命周期模板和可选群专属策略；新增群自动继承模板，正式运价默认永久保留，待处理队列永不参与清理。
- 页面实时展示正式识别、待生效和不合格明细，以及群队列积压、Excel更新方式、心跳和重连次数。
- “数据与报表”集中提供历史筛选、分页、日均统计、单条/勾选删除、Excel/CSV在线预览与下载、走势图预览。详见 [数据查询与报表管理](docs/10-数据查询与报表管理.md)。
- Excel以每群独立批量追加为主，日/周/月/年汇总低频校准；普通追加不会被其他群阻塞，涉及进程工作目录的全量构建仍安全串行。
- 本机“群与线路管理”页面（含数据生命周期）：`http://127.0.0.1:8765/?view=config`。
- 管理页使用本机Host/Origin/CSRF校验、配置版本冲突保护和Token脱敏；保存时先排空消息与Excel队列，再在同一进程内重新加载。
- “启动物流运价系统”会先确保监督器运行，读取实际管理端口并等待健康接口就绪，再自动打开实时状态页；无需固定延时或手工刷新。
- 监督器持续恢复异常退出的采集器；对曾经健康但管理接口连续90秒无响应的本项目采集器执行定向重启，不影响其他Python或QQ进程。

## 隐私与安全

- WebUI、OneBot和系统管理页默认只监听 `127.0.0.1`，不要开放到公网。
- 系统管理页代码层只允许IPv4回环地址；已保存的NapCat Token不会通过配置API回传，页面留空表示保留原Token。
- 仓库和发行包不包含实际QQ账号、实际群号、Token、聊天记录、数据库或客户原始报价；测试使用合成标识和脱敏格式样例。
- 建议使用专门用于采集的QQ账号，不要使用日常主账号。
- Release原样包含NapCatQQ官方 `NapCat.Shell.Windows.Node.zip`，附带版本、来源、SHA-256和完整[官方许可](https://github.com/NapNeko/NapCatQQ/blob/main/LICENSE)；不包含腾讯QQ。
- NapCatQQ许可包含非商业使用限制。商业部署前必须自行取得NapCat作者的额外授权。
